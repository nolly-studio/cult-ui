Prompt Composer is a React multiline prompt input for shadcn/ui with an animated gradient rim, a Warp shader avatar from @paper-design/shaders-react, a staggered loading line, and attach and send buttons built on Base UI. Use it as the message input in AI chat apps and agent interfaces.
