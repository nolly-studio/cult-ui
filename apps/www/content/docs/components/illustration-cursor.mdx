Illustration Cursor is a React component for shadcn/ui that renders labeled multiplayer cursors in SVG, each with a name tag and color, drifting with a requestAnimationFrame loop. Use it to illustrate real-time collaboration in landing page sections for editors, whiteboards, or design tools.
