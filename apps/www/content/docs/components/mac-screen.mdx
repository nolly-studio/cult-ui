Mac Screen is a React component for shadcn/ui that places an image or GIF inside the screen of a classic Macintosh computer frame, positioned with percentages so it scales responsively. Use it to show product demos, retro screenshots, or animated previews on landing pages and portfolios.

## Usage

`MacScreen` is a client component. Pass `gifUrl` for any image URL (not only GIFs) to show inside the bezel, and `alt` for accessible text for that inner image.

```tsx
import { MacScreen } from "@/components/mac-screen";

export function Hero() {
  return (
    <MacScreen
      gifUrl="https://example.com/preview.png"
      alt="Product screenshot"
    />
  );
}
```
