Halo Dropzone is a React file upload dropzone for shadcn/ui, part of the Halo kit, with drag-and-drop, click and keyboard selection, an animated dashed rim built with Motion, and file-type glyphs. Use it in upload forms, attachment fields, or AI chat inputs that accept documents.
