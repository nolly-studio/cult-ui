LightBoard is a React canvas component for shadcn/ui that renders text as a grid of scrolling lights, with a default or seven-segment font, custom colors, and mouse or touch drawing. Use it for landing page banners, status tickers, or playful interactive headers.

```tsx

  return (
    <LightBoard
      size={LightBoardSize.Large}
      lightSize={4}
      gap={1}
      text="Hello World"
      font="default"
      updateInterval={100}
    />
  );
};

export default LightBoardDemo;
```
